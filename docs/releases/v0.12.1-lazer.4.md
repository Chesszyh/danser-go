This fork combines upstream danser 0.12.1 with the official osu!lazer rules engine and Apple Silicon macOS support.

- Update the built-in star rating and performance calculation to the 2026 Q3 rework.
- Keep Hyprland/Wayland startup working when the compositor cannot set window icons, and include SDL3 in the Linux desktop installation.
- Update the official osu!lazer source to `c752ffb2260abcf4dad0b7d8e298806ab9db5b24` (2026-10-24).
- Bundle a self-contained official rules host on Linux x86-64 and macOS arm64, with Inter replacements for restricted resource fonts.
- Package FFmpeg 8.1 for Linux recording.
- Update recording synchronization and audio dependencies while preserving the macOS OpenGL 4.1 path and overlapping-object scheduler fixes.

Select `Gameplay.LazerRulesEngine=official` to use the official host. The Linux `danser-lazer` installer enables it by default for a new installation. Stable replays continue to use danser's built-in rules.

The macOS application requires macOS 15 or newer. It is ad-hoc signed; recording uses an external FFmpeg CLI. The source archive and build verification metadata are included with the macOS package.
